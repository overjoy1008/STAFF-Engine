# STAFF UI Profile — HTML/SVG prototype

STAFF의 체력·자원 프로필을 검토하기 위한 로컬 웹 프로토타입입니다. HTML, CSS, JavaScript, SVG로 구성되어 있으며 설치나 빌드가 필요 없습니다. Unity HUD에 연결되거나 전투 이벤트를 자동으로 받는 상태는 아닙니다.

## 실행

STAFF Engine 저장소 루트에서 실행합니다.

```sh
python3 Tools/UIProfile/serve.py
```

[프로필 열기](http://127.0.0.1:4179/#profile) · [체력 White/Black 비교](http://127.0.0.1:4179/#vital)

포트를 바꾸려면 `python3 Tools/UIProfile/serve.py --port 4180`으로 실행합니다. `Ctrl+C`로 종료합니다. 파일을 수정하고 브라우저를 새로고침하면 반영됩니다. `index.html`을 브라우저에서 직접 열어도 실행됩니다.

## 화면과 조작

- **01 CYCLICAL**: 초기 원형 그래픽 스터디와 원본 비교.
- **02 VITAL ARCS**: 같은 체력을 White/Black 두 배경에서 비교.
- **03 PROFILE**: 체력 원, 작은 빨강 삼각형 8개, 파랑 평행사변형 게이지, 큰 보라 삼각형 3개.

체력은 슬라이더, `1 / 4 / 8 / 12` 프리셋, `DAMAGE / HEAL / RESTORE`로 조절합니다. `PAUSE`와 `SPEED`로 움직임을 확인합니다. Space는 현재 섹션의 재생을 전환합니다.

빨강 삼각형은 클릭·터치하거나 쓸어서 여러 개를 켜고 끕니다. 꺼진 칸에서 시작하면 켜고, 켜진 칸에서 시작하면 지웁니다. `CHARGES` 슬라이더도 사용할 수 있습니다. 파랑 게이지는 직접 누르거나 드래그·터치하여 조절하고, `ENERGY` 슬라이더와 연동됩니다. 게이지에 포커스하면 방향키, Page Up/Down, Home/End도 사용할 수 있습니다. 큰 보라 삼각형은 데모 확인용으로 직접 켜고 끌 수도 있습니다.

## 현재 구현 규칙

| 구성 | 구현 |
| --- | --- |
| 체력 | 최대 12. 호 1개가 체력 1이며 0이면 모든 호가 사라짐. |
| 궤도 | 반지름 52/74/96/118/140/162의 6개 고정 궤도. 호는 1/2/3/1/2/3개씩 배치. 같은 궤도는 위치 차이·속도·방향을 함께 유지. |
| 회전 | 궤도마다 다른 고정 패턴으로 가속·감속·역회전. 난수와 seed를 사용하지 않음. |
| 피해 | 전체 도형이 짧게 흔들리고, 잃은 호가 빨갛게 짧아지며 사라짐. |
| 회복 | 호 성장 0.66초, 고속 회전 480도/초. 새 궤도만 시작점을 정렬하고, 기존 궤도는 현재 위치에서 같은 고속 회전에 합류. 이후 각자의 패턴으로 복귀. |
| 회색 부채꼴 | 별도 각도로 20도/초 역회전. 체력이나 회복 가속의 영향을 받지 않음. SPEED는 전체 재생 속도에 반영. |
| 빨강 | 작은 정삼각형 8개의 충전 상태. |
| 파랑 | 0~100% 평행사변형 게이지. 감쇠 보간으로 부드럽게 채우고 비움. 채워진 부분의 네 변이 발광. |
| 보라 | 큰 정삼각형 3개. 빨강 8개와 파랑 100%가 실제 채워지면 두 자원을 소모해 빈 보라 하나로 전환. 3개가 모두 차면 자원은 소모하지 않음. |
| 기본값 | PROFILE 체력 9/12, 빨강·파랑·보라 비어 있음. VITAL ARCS는 체력 12/12. |

빨강·파랑이 공격·회피·가드에 따라 차는 전투 획득 조건은 아직 구현되지 않았습니다. 현재는 위 입력으로 시뮬레이션합니다.

시각 구성은 정삼각형과 게이지의 60도 사선 정렬, 뾰족한 스트로크, 단색 LED 채움·글로우·스캔라인을 사용합니다. 빨강 `#ff5062`, 파랑 `#7f95ff`, 보라 `#cb90ff`입니다. `prefers-reduced-motion`에서는 기본 공전·흔들림·회복 가속과 스캔라인 이동을 줄이거나 끕니다.

## 코드 위치

| 파일 | 역할 |
| --- | --- |
| `index.html` | 세 섹션과 조작 UI. |
| `vital-component.js` | `createVitalDisplay(options)` 공통 체력 컴포넌트. 궤도, 피해·회복, 부채꼴, 입력, 체력 상태를 인스턴스별로 관리. |
| `vital.js` | 섹션 2의 White/Black 두 디스플레이 생성. |
| `orbit-motion.js` | 6개 궤도의 고정 속도 패턴과 주기. |
| `profile.js` | 섹션 3의 체력 인스턴스, 삼각형·게이지 SVG, 네온·터치·자원 전환. |
| `vital.css`, `profile.css` | 체력 및 프로필의 레이아웃과 효과. |
| `navigation.js`, `navigation.css` | 섹션 메뉴와 현재 섹션 판별. |
| `app.js`, `style.css`, `assets/reference.png` | 첫 CYCLICAL 스터디와 비교 이미지. |
| `serve.py` | Python 표준 라이브러리만 사용하는 로컬 서버. |

공통 컴포넌트는 `createVitalDisplay({sectionId, prefix, mounts, initialHP, frame})`으로 생성하며 `setHP(value)`, `getHP()`, `toggle()`을 제공합니다. 2번과 3번 섹션은 같은 코드를 사용하지만 체력과 재생 상태는 독립적입니다.

## 검증과 레퍼런스

Chrome에서 삼각형의 정삼각형 비율·사선 정렬, 체력 변화·궤도 동기화, 네온 테두리, 게이지의 부드러운 증감, 마우스·실제 터치 드래그, 자원 전환·최대치, 모바일 가로 넘침을 확인했습니다. Unity 씬·플레이모드 검증을 의미하지 않습니다.

CYCLICAL의 비교 이미지는 사용자가 제공한 레퍼런스입니다. 원작자 정보로 Mark Jones(MUCHI)가 전달되었고 [포트폴리오](https://muchi.artstation.com/)에 Orrery가 있지만, 상세 작품과의 직접 대조 및 별도 이용 허락은 확인되지 않았습니다. 첨부 이미지를 이 프로토타입의 자체 제작 에셋으로 간주하지 않습니다. 프로필의 배치와 동작은 사용자의 스케치 및 이 작업에서 정한 UI 규칙을 따릅니다.
